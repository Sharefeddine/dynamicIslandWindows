# Ideas for a future version

These are suggestions, not features already implemented.

## UI and UX

1. **First-run setup and diagnostics:** guide users through microphone permission, recognizer availability, a test command and media-session troubleshooting.
2. **Accessibility and personalization:** adjustable font sizes, high-contrast themes, reduced motion, and more complete screen-reader and keyboard support.
3. **Monitor and layout settings:** choose a monitor, remember the JARVIS position and handle display/DPI changes while running.
4. **Command history:** show a scrollable local history with timestamps, copy/clear actions and a clear distinction between tentative and finalized speech.
5. **Media source picker:** list Windows media sessions so a user can choose which player is displayed and controlled.

## Feature ideas

1. **Richer media card:** real artwork and seeking when a player exposes them; use session-specific play and pause rather than only system media-key toggles.
2. **Focus options:** configurable durations, long breaks, optional automatic cycles and a clear pause/resume policy after sleep or restart.
3. **Reminders:** repeat schedules, snooze and quiet hours, plus opt-in Windows-scheduled notifications that can work when the app is closed.
4. **To-do and shelf improvements:** edit tasks and due dates, export/backup local data, locate missing files and open their containing folders.
5. **Speech settings:** select an installed recognizer and language, show an input level and offer adjustable confidence. Add more local commands with confirmation for sensitive actions.
6. **Windows settings:** optional startup at login, a shortcut editor and per-feature privacy controls.

Before adding features, validate the existing Windows behavior with a real microphone, several browsers and media players, multiple displays, high-DPI scaling, file drag-and-drop, and notification settings.
