# Ideas for a future version

These are suggestions, not features already implemented.

## UI and UX

1. **First-run setup and diagnostics:** guide users through microphone permission, recognizer availability, and a test command; show why media or speech is unavailable.
2. **Compact and expanded modes:** allow resizing, repositioning, and choosing a monitor; remember the user's layout.
3. **Clearer command feedback:** add a scrollable local history with timestamps, copy/clear actions, and an explicit indication of tentative versus finalized speech.
4. **Accessibility and personalization:** keyboard navigation, adjustable font sizes, high-contrast themes, and reduced-motion settings.
5. **Media source picker:** show available Windows media sessions so the user can choose which player is displayed and controlled.

## Feature ideas

1. **Richer media card:** album/video artwork, elapsed time and seeking where the player exposes them, with explicit unavailable states.
2. **Targeted playback controls:** use a selected media session's separate play and pause actions instead of relying only on system media-key toggles.
3. **More local commands:** open selected apps, set timers, or control volume, with an editable command list and confirmation for sensitive actions.
4. **Speech settings:** choose an installed recognizer and language, show a microphone input level, and offer adjustable recognition confidence.
5. **Useful Windows signals:** optional notifications, calendar reminders, network state, and battery alerts with per-feature privacy controls.
6. **Tray and startup settings:** opt-in launch at login, a global shortcut editor, and easy pause/exit controls.
